claude/GPT 环境隔离

1、准备工作
  - 随便一个梯子，打开 tun 模式，
  - 一个固定家庭IP，这里可以购买：https://share.cliproxy.com/share/dppteosng（支付宝支付需要先关闭梯子）
  - 安装指纹浏览器 AdsPower：https://www.adspower.net/

2、操作流程
  - AdsPower 中【新建浏览器】，然后将你买的固定 IP 的账号密码端口都填到代理那一栏
  - 以 cliproxy 购买的代理为例，代理方式选择自定义，代理类型选择Socks5，IP 查询渠道随意，主机端口/账号/密码 输入你在 cliproxy 中买的。
  - WebRTC 选择禁用，时区/地理位置/语言 选择基于 IP（如果显示的 IP 地址和你购买的 IP 归属地不同，你就手动选择到你固定 IP 对应的），其他默认就行
  - 确定完成配置后点击【打开】，会出现一个类似 chrome 的浏览器
  - 默认会出来一个 IP 查询渠道，应该会显示你的固定 IP 的地址，如果和你购买的地址对不上（可能是 IP 查询渠道没正确查到），可以使用 ping0.cc 来再查询确认一下
  - IP 没问题后就可以在这个浏览器中操作 google 和 claude/GPT 账号了

3、claude code/codex 本地环境
  - https://github.com/SimpleTang/ai-sandbox 按照这里的容器教程来安装


使用国内信用卡订阅 claude/GPT 完整教程。

1、准备工作
  - 梯子
  - 一个 google 账号
  - claude/GPT 账号，可以直接使用 google 账号登录
  - 一张支持 visa 的国内双币种信用卡
  - 一个 Android 手机

2、操作流程
  - 挂上梯子打开 google wallet（wallet.google.com）
  - 选择【支付方式】-【添加支付方式】，然后按照要求填入你的信用卡信息
  - ！注意！，账单地址选择一个免税地区可以少支付一些税，且 google 账号归属地是根据账单地址决定的。
  - Android 手机挂上梯子打开 google play 商店，安装 Claude/ChatGPT app
  - 登录后直接使用 google 账号进行订阅并支付
