# 已验证的应用经验

每一节都来自真机实测。日期是验证时间,应用升级后可能变化;发现对不上时以截图为准,并在 local-notes.md 里记下差异。

## 微信(com.tencent.xinWeChat)

2026-10-30 验证,微信 4.x。

- **界面是自绘的**:元素树里只有窗口的三个按钮和菜单栏,联系人列表、聊天内容、输入框都读不到。只能看截图、按坐标点击、用键盘输入。
- **找主窗口**:`launch_app` 会返回十几个窗口。主窗口的标题是「微信」,`is_on_screen` 为真,尺寸最大(约 985×740 点)。
- **打开会话**:在左侧会话列表里点联系人那一行(坐标取截图里该行的中部)。后台点击是生效的,但界面要 1~2 秒后才切换过去;先等一下再截图,不要重复点。
- **搜索不可靠**:`hotkey(["cmd","f"])` 经菜单调用了「编辑 → 搜索」,但搜索框并没有获得焦点。这时 `type_text` 打出的字会进入**当前会话的输入框**。联系人不在列表可见范围内时,先滚动列表找;用搜索框需要先按坐标点击它,这条路线还没验证。
- **输入和发送**:打开会话后,`type_text` 会进入输入框;按回车(`press_key(key="return")`)就是发送。输错了用 `press_key(key="delete")` 逐字删。
- **发送前核对**:右侧顶部是会话标题,看清楚是不是要找的人;同名联系人、备注名、带「AI」标签的 AI 助手要区分开。输入框里只有要发的内容时再按回车。发出后,截图里会出现右侧的绿色气泡,左侧列表里该会话的最后一条也会变成这句话。

## 网易云音乐(com.netease.163music)

2026-10-30 验证。

- **界面是自绘的**:主界面读不到元素,但菜单栏完整。
- **播放控制走菜单**:`invoke_menu(path=["控制", X])`,`X` 可以是:播放(播放和暂停是同一项)、下一个、上一个、升高音量、降低音量、喜欢歌曲、随机播放、打开/关闭歌词。「循环播放」下面还有子菜单:关、单曲、全部。
- **核对播放状态**:看底部播放条中间的按钮。正在播放时是暂停图标(两条竖线),同时显示当前歌名和歌手。
- **启动后可能弹窗**:例如「x.y.z 版本发布」。点弹窗右上角的 × 关掉,不要点「现在更新」。
- 首页的推荐卡片(每日推荐、私人漫游等)只能按坐标点击,还没有验证过。

## 计算器(com.apple.calculator)

2026-10-29 验证。

- **标准应用**:按钮都有名字。中文系统下是:全部清除、删除、加、减、乘、除、等于、点、百分比、更改正负号,以及数字 0~9。
- **推荐写法**:`run_steps(pid=..., window_id=..., steps=[{"click":{"role":"button","name":"全部清除"}}, {"click":{"role":"button","name":"7"}}, ...])`。
- **读结果**:元素树里窗口下的 `AXStaticText` 就是显示值,前面可能带一个不可见字符。
- **单例应用**:两个 agent 同时操作同一个计算器窗口时,会互相让对方的 `element_token` 失效;改用按名字定位,或者错开时间。
- 「编辑 → 拷贝」等菜单项在应用处于后台时是禁用的,`invoke_menu` 会报 `path segment ... is disabled while the app is in the background`。
